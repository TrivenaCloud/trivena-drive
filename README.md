# Trivena Drive


> **Developers:** use the shared Trivena toolchain — see [CONTRIBUTING.md](./CONTRIBUTING.md) and [trivena-development docs](https://github.com/TrivenaCloud/trivena-development/tree/main/docs).


File storage and sharing for Trivena Cloud.

## Hosted

Use on [Trivena Cloud](https://cloud.trivena.tech) — install from the Marketplace or include it when you create a Site.

## Self-hosted

```bash
bench get-app https://github.com/TrivenaCloud/trivena-drive.git
bench --site <site> install-app drive
```
